# Stopwatch Web Application

A simple and interactive stopwatch web application created using HTML, CSS, and JavaScript. The application allows users to measure elapsed time with start, pause, reset, and lap functionality.

## Features

- Start the stopwatch
- Pause the stopwatch
- Reset the stopwatch
- Record lap times
- Display elapsed time accurately
- Simple and user-friendly interface
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript
